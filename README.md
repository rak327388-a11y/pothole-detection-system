\# Real-Time Pothole Detection System



\## Project Overview



A real-time computer vision system for detecting and localizing potholes using YOLO deep learning technology.



The system detects potholes from road images, recorded dashcam videos, and live camera feeds. GPS integration is planned to automatically geotag detected potholes and display their locations on a map.



\## Objectives



\- Detect potholes using YOLO.

\- Localize potholes in images and videos.

\- Support recorded dashcam videos.

\- Support live camera input.

\- Provide detection confidence scores.

\- Integrate GPS for pothole geotagging.

\- Map detected potholes.

\- Support future real-world vehicle and bus applications.
